# Исправления alpha.35

- Подписи апоцентра и перицентра на самой орбите используют переведённый текст, а не строковое представление объекта `Component`.
- Рядом с выбором цели в планере есть кнопка `×` с подсказкой «Сбросить цель сближения». Она снимает выбор непосредственно, без перебора каталога; изменение проверяется сервером и сохраняется.
- Попытки естественного появления фантомов для игроков внутри космических областей запрещены через `PlayerSpawnPhantomsEvent`, включая игроков на конструкциях. Правила появления фантомов на поверхности сохраняются.
- В космосе не воспроизводятся звуки категории погоды и гром Minecraft/Simple Clouds. При входе также останавливаются уже звучащие погодные звуки. Остальные звуки продолжают работать; состояние погоды мира не меняется.

Проверки: серверный тест события появления фантомов внутри области и на поверхности; клиентская проверка подавления грома, сохранения обычных звуков и погоды на поверхности, а также сброса цели кнопкой с проверкой серверного состояния.
