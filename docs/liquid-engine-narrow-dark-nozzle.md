# Более узкое и тёмное сопло — alpha.53

Поперечные размеры профиля сопла уменьшены на 20%. Максимальная ширина теперь 13,76 модельного пикселя — около 0,86 блока, вместо 17,2 пикселя. Все вершины модели укладываются в ширину блока; нижний выступ по высоте сохранён. Изгиб профиля Лаваля и квадратное сечение не меняются.

Для внешних стенок сопла вместо железа используется тёмный полированный глубинный сланец (`polished_deepslate`). Верхнее крепление сохраняет прежний материал. Внутренняя облицовка, её свечение и ширина струи согласованы с уменьшенным профилем через общий генератор. Расход и масса не менялись.

Проверена геометрия OBJ: все координаты X/Z находятся в диапазоне блока [0, 1].

Клиентская проверка с Create/Pondus/Sable/Cruising/DH/Simple Clouds прошла: модель, активная струя и свечение, выключенное состояние. Контрольные кадры просмотрены.
