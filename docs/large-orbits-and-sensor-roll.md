# Большие орбиты и крен датчика — 0.11.0-alpha.28

Убрано прежнее ограничение 168000 тиков для выбора и сохранения узлов.
Лимит количества узлов (16) и диапазон компонент Δv (±10000 м/с) сохраняются.
Продолжительность замкнутой орбиты теперь определяет длину прогноза: показывается
полный оборот, даже если он занимает много часов или дней. Пересечение границы
возврата на планету по-прежнему завершает дугу; незамкнутые траектории имеют
конечный отображаемый участок.

Геометрия эллипса и время его точек рассчитываются через эксцентрическую аномалию.
Это улучшает детализацию удалённой части сильно вытянутой орбиты. Построение не
перебирает прошедшие тики и не становится пропорционально дольше из-за периода.
Повторяющиеся витки перед очень далёким узлом не рисуются многократно.
При щелчке время дополнительно уточняется по настоящей траектории Кеплера,
поэтому выбранный узел соответствует месту на кривой. Сервер больше не отклоняет
его только из-за превышения прежнего двухчасового окна. Существующие планы
используют прежний формат хранения.

Датчик ориентации получил свойство `roll` 0…3: четыре варианта крена для каждого
из шести направлений носа, всего 24 ориентации. Старые блоки получают `roll=0`.

Обычный клик ключом Create (без Shift) по носу или противоположной грани
поворачивает красную/золотую стороны вокруг оси носа. Два таких клика меняют
их местами. Клик по боковой грани поворачивает весь прибор вокруг этой оси.
Сохраняются режим, масштаб сигналов, привязка шлема и экземпляр block entity.

Новая ориентация согласована между статической моделью, движущимся индикатором,
редстоуном и авиагоризонтом AeroEngine. Вращения структур тоже учитывают крен.
RSU, двигатели и планировщик продолжают использовать свой обычный поворот ключом.

Проверено: полное замыкание прогноза после импульса с периодом дольше старого
ограничения, координаты и даты дальней части эллипса, последовательные узлы;
клиентский сценарий с узлом более чем за восемь часов вперёд и повторным открытием.
Настоящий Create wrench проверяет цикл четырёх кренов на каждом из шести креплений.
