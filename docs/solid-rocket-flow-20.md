# Расход твердотопливного двигателя 20 кг/с — alpha.64

Расход увеличен с 16 до 20 кг/с. Энергия топлива и скорость истечения сохранены: при стандартном множителе энергии скорость остаётся 800 м/с, тяга теперь составляет 16000 Н вместо 12800 Н. Один полный заряд при стандартных коэффициентах массы горит 3,2 секунды вместо 4. Дополнительные секции продлевают горение, не увеличивая тягу одного сопла.

Изменение увеличивает стартовую тягу без увеличения доступного delta-v. Учёт массы Pondus, вместимость, порядок выгорания, фиксация запуска и модели сохранены. Расход, фактический импульс, отображаемая тяга и выхлоп используют общий параметр двигателя.

Проверки: все 6 выбранных серверных GameTest с Sable/Create/Pondus прошли при новом расходе. Все 219 модульных тестов и итоговая сборка также прошли.
