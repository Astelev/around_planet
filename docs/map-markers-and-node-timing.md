# Отметки и параметры манёвров — alpha.34

На карте отметки T Ap/T Pe, AN/DN и точки минимального сближения подсвечиваются при наведении так же, как апоцентр и перицентр своей орбиты. Подсказка показывает полное название, высоту, скорость и время до точки. Для узлов пересечения плоскостей дополнительно показан взаимный угол орбит, для сближения — расстояние и относительная скорость.

При наложении отметок приоритет имеют отметки после манёвра. Цвета параметров цели и взаимного наклонения в левом верхнем углу соответствуют цветам отметок: фиолетовый для цели, голубой для текущих узлов и оранжевый для узлов после манёвра.

В редакторе выбранного манёвра поле «Через, с» задаёт время до него. Кнопки рядом сдвигают абсолютное время манёвра на выбранный шаг 1/10/100 секунд. Изменение времени пересчитывает последующие участки траектории.

Поле «Предупр., с» теперь относится к выбранному манёвру. Планер выдаёт редстоун-сигнал в течение этого интервала перед его точкой. Разные манёвры могут иметь разные интервалы. Параметр сохраняется вместе с узлом, передаётся серверу и сохраняется при `/time warp`. Старые манёвры без индивидуального значения используют прежнюю настройку планера.

Формат сетевых пакетов манёвров обновлён: клиент и сервер должны использовать одну версию мода.
