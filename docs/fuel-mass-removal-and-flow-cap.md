# Масса после снятия оборудования, плотность топлива и расход — alpha.49

Убран полный пересчёт массы всего аппарата, добавленный в alpha.48 после сборки заправленного двигателя. С ним восстановление содержимого из NBT расходилось с кэшем Pondus. Теперь после сборки синхронизируется только наш двигатель через штатный `InventoryChangeListener.onInventoryChanged` Pondus. Без Pondus добавляется только массовый вклад топлива нашего двигателя. Другие баки и контейнеры этот этап не затрагивает.

Отдельно исправлено удаление бака Create: при изменении блока его контроллер уже мог стать недоступен, поэтому из массы конструкции вычиталась лишь сухая масса. Для удаляемого бака используется уже учтённое значение из кэша Pondus. Если штатный расчёт уже включил содержимое, повторного вычитания нет. Эта совместимость ограничена баками Create и нашим жидкостным двигателем; формулы наполнения и расхода Pondus остаются прежними.

Содержимое ведра жидкого водорода теперь имеет массу 1 кг при стандартных множителях. Кислород масштабирован тем же коэффициентом: примерно 16,104446 кг на ведро. Соотношение плотностей и массовое соотношение смеси сохранены. Старые значения по умолчанию 70,85/1141 кг мигрируют при запуске; отличающиеся пользовательские записи Pondus сохраняются. Масса металлической тары учитывается Pondus отдельно. Прочие жидкости и общие множители Pondus не меняются.

Максимальный расход смеси — 30 кг/с. Новые двигатели начинают с 1 кг/с. Ограничение действует в интерфейсе, серверной настройке и при загрузке прежнего NBT, включая сохранённые значения 50–1000 кг/с.

Нативные проверки с настоящим Pondus воспроизводят корпус из восьми блоков земли, заправленный двигатель и баки Create. Проверяются наполнение, откачка, удаление одиночного и составного баков. После снятия оборудования масса равна 12 кг при массе земли 1,5 кг; центр массы и инерция совпадают со свежим расчётом оставшихся блоков. Общая регрессия с Pondus: 67 серверных тестов прошли.

Дополнительно прошли 67 нативных тестов без Pondus, 26 автономных игровых тестов и 8 целевых тестов с Pondus, включая миграцию прежних плотностей с сохранением пользовательских значений.
