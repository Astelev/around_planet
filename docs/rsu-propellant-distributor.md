# Распределитель рабочего тела RSU — alpha.71

RSU больше не создают бесплатную тягу. Установите на ту же физическую конструкцию блок **«Распределитель рабочего тела RSU»** (`around_planet:rsu_distributor`). Он имеет внутренний бак 8000 мВ (8 вёдер), принимает любую жидкость через стандартную fluid capability со всех сторон, трубы Create и ведро. Щелчок пустой рукой показывает заполнение. Блок доступен в творческой вкладке редстоуна, добывается киркой. Разрушение блока теряет содержимое, как у внутренних баков двигателей.

Трубы к отдельным RSU не нужны. Распределитель обслуживает все загруженные RSU **того же Sable-саблевела**, независимо от расстояния внутри него. Соседние, отделённые или просто находящиеся в том же космическом пространстве конструкции рабочее тело не разделяют. Несколько распределителей суммируют доступный запас. Используются только зарегистрированные загруженные блоки: сканирования чанков, принудительной загрузки и фоновых потоков нет.

Скорость выброса фиксирована: **800 м/с**. Для каждого физического подшага запрашивается масса `Σ(F × dt) / 800`, где F учитывает тягу и уровень сигнала каждого сопла. Например, одно сопло 500 Н требует 0,625 кг/с, четыре — 2,5 кг/с. Противоположные сопла расходуют рабочее тело даже при нулевой результирующей силе. При нехватке все сопла всех RSU на конструкции получают одинаковый коэффициент снижения тяги, чтобы порядок обхода не нарушал баланс управления.

Объёмный расход зависит от массы жидкости. С Pondus читаются его запись жидкости, глобальный коэффициент и inventory multiplier блока. Собственные формулы обновления массы Pondus не заменяются. Для неизвестной ему жидкости регистрируется только отсутствующая базовая масса по плотности fluid type (при плотности 1000 — 1 кг/ведро), существующие записи сохраняются. Без Pondus используется эта же базовая плотность и штатное изменение вклада массы блока в Sable, включая заполнение, выкачивание и пересборку.

Жидкость списывается целыми мВ **до** приложения силы. Неиспользованная часть уже оплаченного импульса (менее стоимости одного мВ) сохраняется между подшагами и в NBT. Это не позволяет получать бесплатный импульс из округления маленьких расходов. SIMULATE не меняет бак; перезапуск не обнуляет остаток. Смена жидкости не меняет ранее оплаченный импульс. После исчерпания запаса тяга и визуальный выхлоп прекращаются; сетевые обновления выхлопа идут с обычным интервалом двигателей.

Изменение не меняет предел RSU 500 Н, частоты Create, креативный и жидкостный двигатели. Общий множитель эффективности ракетного топлива не изменяет фиксированные 800 м/с рабочего тела RSU.

Проверки: 238 модульных тестов, все 92 серверных регрессионных проверки с Pondus и 4 выбранные проверки без Pondus. Проверены произвольные жидкости (вода, лава, жидкий водород), SIMULATE, сохранение оплаченного остатка, несколько RSU, симметрия при голодании, отсутствие расхода/тяги без топлива, разделение кораблей и возврат к сухой массе после выкачивания и загрузки.
