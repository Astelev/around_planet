# Стабильная масса и центр масс при пересборке — alpha.66

Исправлена совместимость Around Planet с Pondus Inventory 0.15-Beta и Sable 2.0.6 при полном пересчёте массы конструкции. Номинальные массы блоков и топлива, множители Pondus и параметры двигателей не изменены.

## Причины

Sable передаёт в `MassTracker.build` ускоренную обёртку `BlockGetter`, а Pondus читает инвентарь только из `Level`. Полный пересчёт из-за этого терял содержимое и не обновлял соответствующий кэш. Последующие изменения содержимого применялись к несогласованной базе.

Для многоблочных ёмкостей есть ещё два расхождения. Пересчёт Pondus учитывает инвентарь только у контроллера, хотя штатная модель распределяет массу содержимого по всем ячейкам. Его обработчик центра масс возвращает абсолютный центр многоблока в месте, где Sable ожидает смещение внутри отдельного блока и затем сам добавляет координаты ячейки. Это смещает центр масс даже пустого симметричного бака.

При разборке широкого бака последовательность разделения ёмкости Create и инкрементальных обновлений Pondus могла оставить правильную суммарную массу, но неверный центр масс и инерцию остатка. В тесте после снятия бака центр оставшегося корпуса смещался на 0,91 м.

Также кэш общей массы многоблока, используемый при изменении блоков, мог сохранять значение до откачки, несмотря на обновление поячеечного учёта.

## Изменения

- Для полного пересчёта раскрывается обёртка до исходного мира, чтобы Pondus видел содержимое и заполнял свой кэш.
- Каждая ячейка многоблока получает массу через штатный `PhysicsBlockPropertyHelper` с обработчиком Pondus; в кэш записывается именно уже учтённая доля содержимого.
- Центр такой ячейки передаётся в локальных координатах `(0.5, 0.5, 0.5)` в обоих проходах расчёта, включая инерцию. Распределение массы по ячейкам сохраняется.
- Общий кэш многоблока обновляется штатным методом Pondus перед обработкой изменения содержимого и при инициализации учёта.

- После добавления/удаления блока бака или хранилища Create выполняется один штатный пересчёт Sable в конце тика. Изменения одного корабля объединяются, расход жидкости этого пересчёта не запускает.

Поправки включаются только при наличии Pondus. Периодического пересчёта всех кораблей не добавлено. Уже испорченный инкрементальный учёт исправляется полным пересчётом при загрузке или пересборке конструкции.

## Проверка

Целевые серверные тесты запускаются отдельно через `-PplanetTests -PplanetMassTests`: они временно меняют глобальные настройки Pondus и поэтому не смешиваются с тестами изменения плотностей топлива. Проверяются заполненный бак Create 3×3×2, четыре цикла наполнения/откачки/пересчёта, повторные переносы и пересчёты с множителем массы блоков 2, снятие широкого бака после частичной откачки и пересчёта. Сравниваются масса, центр масс и инерция оставшегося корпуса.

При низкоуровневом переносе тестового многоблока явно восстанавливаются ссылки Create на контроллер: `SubLevelAssemblyHelper.moveBlocks` сам по себе не выполняет Create `StructureTransform`. Это подготовка тестовой ёмкости, а не изменение игровых ссылок или алгоритма массы.

Проверено: все 6 целевых серверных проверок, все 84 серверных регрессионных теста с Sable/Create/Pondus/Deep Seas и все 219 модульных тестов прошли; производственный JAR собран без тестовых и сторонних классов.
Дополнительно прошли 6 серверных проверок с Sable/Create без Pondus и 5 проверок самостоятельной установки без Sable/Create/Pondus.
