# Падение на частицах реголита — alpha.73

В пользовательском логе перед зависанием зафиксировано `ReportedException: Exception while adding particle`. Причина — `NullPointerException` в `ClientLevel.getBlockTint`, вызванном обработчиком `MoonBlockColors` из конструктора `TerrainParticle`. Цепочка дошла туда через частицы бега игрока. После ошибки клиент начал аварийную остановку встроенного сервера и ожидал завершения его работы/очередей DH, что выглядело как бессрочное зависание игры.

В alpha.72 обработчик реголита передавал собственный `ColorResolver` без регистрации. `ClientLevel` создаёт кэши оттенков только для известных резолверов; для неизвестного объекта кэш отсутствовал. Ошибка могла проявляться на частицах бега, удара/разрушения и других путях, использующих настоящий ClientLevel вместо промежуточного рендер-кэша чанка.

Теперь резолвер имеет постоянную идентичность и регистрируется через NeoForge `RegisterColorHandlersEvent.ColorResolvers` до создания клиентских уровней. Окраска блока всегда использует именно этот объект. Лунная палитра, серый цвет реголита на Земле, биомы, рельеф и сохранённые чанки не изменяются.

Новый тест настоящего клиента создаёт реголит в Overworld, проверяет его цвет через ClientLevel и вызывает обычный провайдер TerrainParticle, частицы разрушения и удара. Затем переносит игрока на настоящую лунную поверхность и повторяет те же проверки после создания нового клиентского уровня. Это воспроизводит путь окрашивания из пользовательского исключения, а не только отрисовку сферы на карте.

После исправления настоящий клиент с Sodium/Sable прошёл проверку частиц в обоих измерениях (`REGOLITH_CLIENT_PASS`); снимок настоящей лунной поверхности просмотрен. Модульная регрессия и производственная сборка также прошли (246 тестов). Серверный генератор и орбитальная механика этим исправлением не затрагиваются.
