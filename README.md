# around_planet

Самостоятельный мод для Minecraft 1.21.1 / NeoForge 21.1.256, Java 21.
Название и mod ID: `around_planet`. Цель — зацикленная планета.

## Текущее состояние

Подготовлена чистая основа нового мода. Зацикливание пока не реализовано:
мод не меняет генерацию, координаты, движение, физику, загрузку чанков или рендеринг.
Выбрана плоская поверхность с переходом на противоположный край по X и Z.
Размер планеты и способ согласования генерации на шве ещё предстоит определить.

Код Cruising Speed удалён из этого репозитория. Его биомная поверхность,
оптимизации DH и Sable, конфиги, шейдеры, сетевые пакеты и mixin-перехваты
остаются в отдельном моде `cruising`. Оба мода имеют разные пространства имён
и могут устанавливаться вместе. around_planet не требует Cruising Speed или DH.

План совместимости и этапы реализации: [docs/architecture.md](docs/architecture.md).

## Разработка

```sh
bash ./gradlew build
bash ./gradlew runClient
bash ./gradlew runServer
```

Результат: `build/libs/around_planet-0.1.0.jar`.
Для совместного запуска можно передать каталог с тестовыми модами:

```sh
bash ./gradlew -PcompatModsDir=/absolute/path/to/test-mods runClient
```

JAR-файлы из этого каталога используются только при локальном запуске и не
включаются в итоговый мод. Не храните пользовательские миры в тестовом `run/`.
